# Experiment catalog — RTX 5090

**English** | [Português (Brasil)](../rtx5090/experimentos.md) · [English index](README.md)

Documentation consolidated on September 12, 2026, starting from the [handoff](../history/handoff-2026-09-12.md). No benchmarks were run to create this catalog. Final corrections in the reports take precedence over their opening summaries. The [September 4 final report](../../RELATORIO-FINAL-2026-09-04.md) is a historical synthesis, not the latest state of every experiment. Historical source reports remain in Portuguese.

## How to read the results

- Generation `tok/s` is `eval_count / eval_duration`; latency includes other costs. The 3080 Ti comparison used a different definition and is not a controlled GPU A/B test.
- The goldset contains 18 customer-support cases. Success in that domain does not measure coding ability.
- `auto_score` changed from 5–6 to 6–7 checks on September 10. Do not combine old and new scores into a ranking. Escalation resampling, full tool-contract validation, and aggregate scores are different metrics.
- **MISS**: the response should have escalated to a human but did not. **LEAK**: the response escalated unnecessarily.
- Scripts under `baseline-3080ti/repro/` were also used on the **5090**. A script's location does not establish the hardware used for a measurement.
- Results without persisted JSON are identified below; a report's existence does not guarantee an auditable raw response.

## Preserved results that are not valid for the main comparison

- [Postfix](../../results/chat_raw.gpu5090-postfix.json): experimental v2 system prompt; escalation-token regression followed by rollback. Incident evidence, not the canonical baseline. [Finding](../../ACHADO-qwen3-14b-pricing-leak-2026-09-04.md).
- Phase 7 without `-v2`: evaluator checked only the first source, accepted numeric substrings, and allowed provenance/search shortcuts. The easy scenario repeated a fixed seed (effective n=1 per model). Do not mix these records with the valid battery.
- Judges `1789042738`, `1789043675`, and `1789043937`: a 1,500-character cutoff hid escalation tokens; superseded by `1789065587` + supplement. `1789065150` is a partial harness test, not the full round.
- String-copy guard: withdrawn; in the evaluated set, 5 LEAKs and 20 legitimate escalations had the same response, giving only 20% precision. The defect depends on the question.

## Pending or outside the measured scope

Phase 5 (coding goldset) has not started, blocked on an execution sandbox. There is no locally established coding winner. Also missing: simultaneous load on both resident models; `keep_alive` after >5 min; isolating the prompt ceiling with NP=1; a spill check that sees speculative models' target; goldset expansion and analysis of concentration by question applied to the model decision. [Historical plan](../../PLANO-fase456-2026-09-05.md) and [handoff](../history/handoff-2026-09-12.md).

The [3080 Ti baseline](../../baseline-3080ti/baseline-3080ti.md) is historical telemetry, with prefill included in the denominator; the final report's near-2× ratio is an optimistic upper bound, not a controlled GPU gain. The 16.9 tok/s `gemma4` run used an **i7-14700KF CPU**, separate from the RTX 5090 judge. See [models and hardware separation](models.md).
